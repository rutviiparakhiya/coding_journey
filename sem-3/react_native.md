core components :
what are components :-
components are reusable building blocks of the UI.

what is the benifit of components :-
Reusability — Write once, use anywhere.
Maintainability — Easier to update and fix bugs.
Organization — Clean and structured code.
Consistency — Same button style across the entire app.

what is view?
it is a basic bulind block of code, It is used to create containers and organize other components.
key benifits :-
it is used to group components together
apply styles (background, padding, margins, flexbox, etc.)
create layouts (cards, rows, columns, containers)

what is scrollview :-
ScrollView is used to see content that is bigger than the screen by scrolling.

safearea view :-
SafeAreaView keeps your app content away from areas like camera cutouts, bottom gesture bar etc.

what is flatlist?
FlatList is a React Native component used to display a list of items. It shows only the items currently visible on the screen, so it works well with large lists.

pressable :-
Pressable is a modern alternative to TouchableOpacity that gives you better control over touches and lets you change styles dynamically when pressed.

safe area view :-
it is a native component that helps our app content stay safe from top, camera cutouts and home indicator or bottom gesture bar

activity indicator :-
it is native component that displays a loding spinner, it is commonly used to show that content is loading.

refresh control :-
it is native component that provides pull to refresh functinoality.

text input :-
it is the equivelent of html input and textarea elements.

touchable opacity :-
TouchableOpacity makes a component clickable and makes it slightly transparent when pressed.
